# Toy Store Sales Analysis Dashboard

This project is my first Power BI dashboard, created to practice data analysis and dashboard design.

## About the Project

The dashboard analyzes sales data from a toy store in the United States and provides insights into sales performance, products, stores, and time-based trends.

## Tools & Technologies

* Power BI
* DAX
* Data Visualization
* Data Analysis

## Dashboard

The dashboard includes:

* Sales overview
* Revenue analysis
* Year-over-Year (YoY) analysis
* Sales trends over time
* Product and store analysis
* Interactive filters

## Project Purpose

This project was created as a learning experience to improve my skills in Power BI, DAX, data analysis, and dashboard design.
